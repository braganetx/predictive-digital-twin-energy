# Security Policy

## Supported Versions

This project adheres to semantic versioning and provides security updates for the primary release line:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

---

## Reporting a Vulnerability

If you discover a potential security vulnerability or algorithmic boundary failure in this open-source research codebase:

1. **Do not open a public issue.**
2. Please report the issue privately to the author:
   * **Adão de Jesus Braga**
   * Email: [braganetx@gmail.com](mailto:braganetx@gmail.com)

We take security and scientific reproducibility seriously and will acknowledge receipt within 48 hours and work with you on a timely resolution.
